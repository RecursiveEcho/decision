# 开工任务卡

总控完成共同基线与 worktree 后，用户同时打开四个新对话。每个对话选择自己的工作目录，不共用一个文件夹。

开场白统一格式（替换角色）：

> $project-handoff 恢复并开始开发。读取当前工作区 PROJECT_STATE.md，交接编号 DECISION-MVP-20261104，再读取 docs/mvp/tasks/A-后端.md。按任务卡完成本角色当日 MVP，实现、自检、提交并推送自己的功能分支，写 handoffs/A.md。保持目录所有权，不改其他角色文件；真实服务未验证须如实标明。用户最终自行试用，工程自检仍由你完成。
