# 本人试用清单

本人验收尚未进行；下面是试用步骤，不预填本人“通过”。建议先用虚构资料熟悉操作。

## 先用三分钟试这条线

1. 打开 http://127.0.0.1:8088 ，从本机 `.local/login.txt` 复制访问码登录。
2. 新建一个问题，写目标和未知项；粘贴一段资料，等后台处理完成后提问“你建议怎么做，依据和未知是什么”。
3. 查看回答的来源和知识主题；自己确认一个决定，再追加一条复盘。页面中已有的“合成验收”记录仅用于工程测试。

当前录屏保持关闭；不要把网页“启用同步”理解为已接好真实观察。小程序真机、手机通知、实际服务器仍未就绪。完整边界和工程证据见 `handoffs/E.md`。

## 详细试用项

| 序号 | 我怎么试 | 我应该看到什么 |
|---|---|---|
| 1 | 打开交付地址，用自己的访问码登录；另用无 token 请求资料 | 能登录；未登录读不到资料；客户端中找不到模型 key |
| 2 | 新建一个问题，写下目标与尚未明确的条件 | 目标和未知项分开；系统不替我补造事实 |
| 3 | 发文章链接；再发一篇粘贴正文；重复点发送 | 成功/部分/读取失败如实显示；同一次操作重试不重复入库 |
| 4 | 打开摘要和 Wiki 主题，再点出处 | 能看到真实来源；Wiki 是实际页面；文章观点没有自动变成我的价值观 |
| 5 | 问“你建议我怎么做，依据是什么” | 使用真实 DeepSeek；建议有理由、不确定性和可回查的来源，允许信息不足 |
| 6 | 在一个无敏感页面启动观察，切换文字内容，再暂停 | 能看到真实新观察、时间和应用；重复内容不淹没记录；暂停后不继续生成新采集 |
| 7 | 输入一份与当前目标存在明显张力的新资料，等待后台处理 | 可形成值得讨论的议题并真实显示桌面通知；若判断无需提醒，应能解释处理状态，不保证每次都提醒 |
| 8 | 对议题选择稍后或忽略，再给相同资料 | 不立刻重复催促；稍后时间与状态正确 |
| 9 | 指出一条记忆错误并修改/删除，然后重新提问 | 不再把旧内容当当前事实；能区分本人修正、模型推断和历史记录 |
| 10 | 明确确认一个决定，然后追加结果 | 保存当时理由；复盘可看原记录，不用新结果覆盖旧依据 |
| 11 | 重启应用服务，再查看对话、资料和决定 | 仍存在；未完成任务没有无限卡住；外部服务失败有可理解提示 |
| 12 | 用小程序登录同一账号继续同一个问题 | 同一条记录可继续，消息不重复；需 AppID/真机条件，未具备时明确标“未验证” |

另记录：哪些提醒有帮助／多余、哪些理解不准确、哪处操作费劲。当天不以“一定做出正确人生决定”作为验收，而是检查是否减少整理负担、暴露关键未知，并给出能讨论的依据。
