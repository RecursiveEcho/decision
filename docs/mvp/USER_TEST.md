# 直接开始聊

打开 http://127.0.0.1:8088 登录，访问码在本机 `.local/login.txt`。

输入一句现在困扰你的事，然后发送。说不清也没关系；不需要先想标题、目标、限制或准备资料。系统自动起名，先回应能帮上的部分，缺关键条件时再逐步问。

图片可以直接粘贴、拖入或点回形针选择，也可上传 PDF、DOCX、XLSX、TXT、MD、CSV。发送前能预览、移除；只发图片也可以。一次最多4个附件，单个8 MiB、合计16 MiB。文件读取不完整时会显示范围。

输入区可选快速、轻度、深度、最高，默认快速；选择后会实际改变模型的思考档位。回答失败时可以“重试回答”，沿用原消息与附件；原话已经保存时也可以“先聊别的”。

正常聊天中的明确个人事实和偏好会自动积累为记忆，不用预先填写。记错了可以直接说，也可以从记忆图标查看原话、纠正或忘记。你明确说出的选择会自动记录；不要求填写决定表，系统不会替你作选择。

历史对话直接列在左侧，左上角可收起侧栏；资料、记忆工具放在底部图标中。窄屏从顶部菜单打开侧栏。来源按短行合并，需要时再展开原文。

## 当前边界

- 本机网页；采集关闭，手机通知和公网部署未启用，小程序真机未验收。
- 模型会出错；一般建议和推断不等于已确认事实。自动记忆仅整理有原话依据的明确本人陈述，不把附件或助手推测算作个人事实；含糊内容可能跳过。
- 旧记录仍可读；更正/撤销资料或记忆后，旧上下文会失效，必要时需要重新说明当前情况。Wiki需独立账号登录。

本轮工程证据见 `CONVERSATIONAL_ASSISTANT.md`；前轮记录见 `CHAT_FIRST.md`、`ACCEPTANCE_ROUND_2.md`。发现哪一句理解错了、哪一步麻烦，直接说即可，不需要替工程团队做整套验收。

启动：`python3 scripts/manage.py up`。停止：`python3 scripts/manage.py stop`，保留数据。TGA只读评估见`HOSTING_ASSESSMENT.md`；未在TGA部署。
