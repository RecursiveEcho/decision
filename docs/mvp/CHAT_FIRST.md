# 一句话直接开聊

开始：2026-11-04 20:07（Asia/Shanghai）。状态：实施中，尚未部署验收。

## 用户目标

用户已经烦恼时，先得到帮助，不能先做信息整理作业。输入一句自然语言即开始；名称自动生成；条件不齐时逐步询问；AI能整理的不要让用户先填。旧版表单功能验收不代表满足这一目标。

## 本轮实现

- A：原子首句创建+消息+Job、同次首答自动命名、无来源有用短回答/至多一个必要问题、失败chat复用用户消息重试。旧接口与数据兼容。
- B：首页/新对话单输入框，用户话立即可见；整理信息与工具折叠但仍可访问；稳定幂等快照、已知Job恢复轮询、失败重试与退出清理。
- E：共享契约、集成部署、真实首轮帮助与第二轮追问验收。接口见CONTRACT，不自动写回推断目标或本人记忆。
