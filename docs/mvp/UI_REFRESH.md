# 聊天界面重构

开始：2026-11-04 21:03（Asia/Shanghai）。状态：2026-11-04 21:24已集成部署并完成工程验证；工程检查不代替本人审美认可。

## 用户要求

侧栏直接列出对话并可收起，工具以小图标展示，右侧聊天入口重新设计。采用成熟产品与组件的好设计并作适合知衡的调整，不只是改颜色，不让用户承担填写设计问卷或重新整理问题的成本。

## 依据与方法

- 应用 Anthropic 官方 [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 技能；已完整阅读。先形成简洁的色彩/排版/布局规则，再实际截图自评。通过 [skills.sh](https://skills.sh/) 查到官方技能，未运行不明来源安装脚本或把技能当产品依赖。
- [assistant-ui](https://www.assistant-ui.com/)：借鉴聚焦输入、连续消息流、轻量空态的结构。不是照搬其聊天运行时，也不更换已验证的后端与状态流。
- [shadcn Sidebar](https://ui.shadcn.com/blocks/sidebar)：借鉴直接列表、可折叠图标栏及移动抽屉交互。保留现有Vue，不为套React示例迁移框架。
- [Lucide Vue](https://lucide.dev/guide/vue)：复用一致的成熟图标，有明确可读名称和提示。
- [markdown-it](https://markdown-it.github.io/markdown-it/)：如启用助手Markdown排版，使用成熟解析器、关闭原始HTML并保留安全链接校验，不以正则自造解析器。

参考页面实际截图和实现截图只放本机忽略证据目录，公开记录不包含用户历史或模型全文。

## 布局方向

```text
桌面展开                     桌面收起
┌──────────┬─────────────┐   ┌──┬─────────────────────┐
│知衡    收│ 顶部轻导航    │   │展│ 顶部轻导航            │
│新对话    │             │   │新│                     │
│历史标题  │ 空态一句话    │   │  │ 居中空态与输入区       │
│历史标题  │ 集中的输入区  │   │图│ 或自然排版的消息流      │
│历史标题  │             │   │标│                     │
│工具图标  │ 对话时底部输入│   │  │ 对话时底部输入         │
└──────────┴─────────────┘   └──┴─────────────────────┘
```

- 约260px侧栏/约56px图标栏；聊天正文约720–800px，避免过长行。手机全宽聊天，侧栏以带遮罩的抽屉打开，不把整块导航堆在正文上方。
- 色彩规则：背景 `#ffffff`、侧栏 `#f6f7f7`、正文 `#202725`、次要文字 `#77807b`、细线 `#e6e9e7`、品牌 `#28665a`。中文PingFang SC/系统无衬线，正文16px/1.75，空态30px中等字重。一级标题、正文、辅助信息有清晰尺度，减少大标题、厚边框与卡片套卡片。
- 输入区是唯一主要焦点，发送按钮有禁用/等待反馈；助手正文自然排版、用户轻气泡。没有无功能附件、语音、模型选择等装饰按钮。
- 图标入口不是隐藏能力：提供标题、无障碍名称、键盘焦点提示及选中状态。折叠与切换不触发业务写入。
