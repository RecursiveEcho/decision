## 实际交付

- 统一 Decision 名称、侧栏与设置。通用、外观、模型与连接、记忆状态、快捷键、关于集中在一个窗口；原生 ⌘, 和网页入口打开同一处，登录前的设置请求会在登录后打开。
- 会话标题/正文搜索并定位原文，固定/分组/归档管理，按需分页，消息复制、查找、返回最新消息。
- OpenAI/DeepSeek 按账号配置、加密保存、模型目录与实际调用测试；会话可选择模型；运行中的请求保留配置快照。普通账号不继承管理员 Key。
- 按会话管理运行，真实流式正文与阶段提示，生成中可切换和编辑其他草稿，停止真正关闭上游，失败显式重试。
- 本机待发送队列可见、可取消；上一轮成功后顺序发送，停止/失败/重开后暂停，明确继续。未发队列不能伪称后台已接受。
- 文字/附件/最后会话/阅读位置按稳定账号保存。登录过期保留草稿；明确退出会清理本机草稿和队列，设置页说明此区别。凭据没有降级放入 localStorage。
- `MemoryClient` 只接本地实现；记忆设置明确中心未连接，预留 Decision、Codex、其他个人 Agent 共用的边界，没有中心网络调用、双写或真实数据迁移。

## 真实界面验收

使用合成账号与附件，Chromium CLI 和 macOS WKWebView 分开记录，界面截图只在忽略的本地输出目录。

- Chromium：设置实际调用/目录、发送键偏好、记忆未连接状态；生成中切换并保留另一会话草稿；可见队列、停止保留partial、刷新恢复暂停、明确继续；正文搜索点击高亮定位；440px窄屏可读；文件选择/暂存；模拟登录过期→切成员看不到旧草稿→重登原账号，原草稿和附件恢复。
- 自动回归补充：异步附件快照期间的新编辑不丢，模型/思考在快照开始固定；附件401不清草稿；附件准备期间登出重登不会卡住；旧会话回包不能改新会话；暂停队列的新消息不插队。
- WKWebView：独立应用启动，原生 ⌘, 登录前意图保留并自动打开统一设置；系统文件选择器选择合成 TXT，文字和附件刷新后恢复；⌘Q停止其自有服务。最终路径包完全退出后重登，文字草稿与TXT附件均恢复；明确退出清理测试草稿后返回登录页。
